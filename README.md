# Smart Trainer Calendar Power BI Report

## Project Overview
This project is an interactive Power BI report designed to simplify trainer scheduling, availability tracking and workforce planning.

## Objective
The objective of this report is to convert daily trainer scheduling data into a clear and practical planning solution for monitoring availability, engagements, leave, internal work and booking status.

## Tools Used
- Power BI
- DAX
- Data Modelling
- Calendar Visual
- Slicers and Interactive Filters

## Report Pages
1. Trainer Workforce Overview
2. Trainer Calendar
3. Trainer 360
4. Schedule Control

## Key Features
- Day-wise trainer calendar
- Trainer availability and engagement tracking
- Reserved, preparation, internal work, leave and weekly-off status tracking
- Trainer 360 profile view
- Workforce utilisation analysis
- Schedule control with client, programme, booking status and delivery details
- Interactive slicers for trainer, month, specialisation, city and employment type

## Key Measures
- Engaged Days
- Available Days
- Leave Days
- Internal Work Days
- Total Engagements
- Trainer Utilisation %

## Learning Outcome
This project helped me understand how Power BI can be used to create practical workforce planning reports that support faster and clearer decision-making.
